# Habitra – AI Productivity & Habit Tracker

A modern habit tracking web app built using React.

## Features
- Add & delete habits
- Mark habits as completed
- Dynamic productivity score
- Streak tracking system
- Dark mode
- Local storage persistence

## Tech Stack
- React.js
- JavaScript
- Bootstrap

## Highlights
- Used React Hooks for state management
- Implemented dynamic UI updates
- Handled initial render edge cases
